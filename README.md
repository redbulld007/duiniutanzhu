# 对牛弹珠

一款为抖音小游戏准备的纵屏 2D 物理弹珠游戏 MVP。玩家从顶部的小牛发射器向下发射弹珠，利用碰撞消耗钉子、触发特殊效果并达成关卡积分目标。

> 当前阶段：可试玩的核心玩法 MVP，商业化与抖音平台接入预留完成。

## 当前玩法

- 顶部拖动瞄准，松开发射；受 Box2D 重力和碰撞影响。
- 绿色、蓝色、灰色牛铃钉分别提供 `3 / 2 / 1` 分，第三次命中后消失。
- 紫色重置钉：恢复所有普通钉子，并移动到新的位置。
- 橙色爆炸钉：触发半径内的普通钉子，且每关只可触发一次。
- 每第 3 球为高弹力球；每第 5 球为分裂球。
- 达标后进入下一关，并获得本地保存的牛币奖励。
- 钉子和特殊钉均有不同的碰撞音效。

完整规则请见 [GAME_DESIGN.md](GAME_DESIGN.md)。

## 技术栈

- Cocos Creator `3.8.8`
- TypeScript
- Cocos 2D Box2D Physics
- 纵屏优先、自适应窄屏棋盘布局

## 本地运行

1. 使用 Cocos Creator `3.8.8` 打开本目录。
2. 等待资源导入完成后，打开 `assets/scene.scene`。
3. 点击 Creator 顶部的预览按钮，在浏览器中试玩。
4. 从顶部小牛附近向下拖动，再松开即可发射。

浏览器通常只会在玩家第一次交互后允许播放音效，因此第一次发射后再检查声音是否正常。

## 目录说明

```text
assets/
├── scene.scene                 # 唯一入口场景
├── resources/art/              # 运行时加载的卡通美术
└── scripts/
    ├── GoblinMarbleMvp.ts      # 主玩法、物理棋盘与 UI
    ├── PhysicsBoardFactory.ts  # Box2D 碰撞体创建工具
    ├── PegSound.ts             # 钉子碰撞合成音效
    ├── GameTelemetry.ts        # 本地优先的埋点抽象
    └── RewardedAdBridge.ts     # 抖音激励视频广告接入点
```

## 抖音小游戏与 IAA

目前广告桥已经具备安全降级：没有广告位时不会影响本地预览或核心玩法。

准备接入时：

1. 在抖音小游戏后台创建激励视频广告位。
2. 将广告位 ID 填入 `assets/scripts/RewardedAdBridge.ts` 的 `rewardedVideoAdUnitId`。
3. 将首次广告入口接到“通关奖励翻倍”等玩家主动选择的奖励上。
4. 在 Creator 的构建面板选择抖音小游戏目标，进行真机调试与构建。
