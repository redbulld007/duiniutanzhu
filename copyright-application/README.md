# 《对牛弹珠》软著申请材料清单

本目录用于准备计算机软件著作权登记材料。请在实名认证通过后，按中国版权保护中心系统的最新页面要求提交。

## 申请信息建议

| 字段 | 建议填写 |
| --- | --- |
| 软件名称 | 对牛弹珠游戏软件 |
| 软件简称 | 对牛弹珠 |
| 版本号 | V1.0 |
| 软件类别 | 游戏软件 |
| 开发方式 | 独立开发 |
| 编程语言 | TypeScript |
| 运行环境 | Cocos Creator 3.8.8；支持 HTML5/移动端小游戏运行环境 |
| 著作权人 | **必须填写与抖音小游戏开发者主体相同的个人或公司全称** |

请勿在证书下发前修改“对牛弹珠”名称、版本号或著作权主体；抖音后台名称与软著名称/简称需保持一致。

## 需要准备的文件

1. 身份证明：个人提交身份证明；公司提交营业执照等系统要求的主体文件。
2. 软件说明书：使用本目录的 [软件说明书.md](软件说明书.md)，补充申请主体、完成日期，并导出为 PDF。
3. 源程序鉴别材料：提交 `assets/scripts/` 内自主开发的 TypeScript 文件，不提交 Cocos 引擎、`library/`、`temp/` 或 `node_modules/`。
4. 游戏截图：从 Creator 预览或真机测试中截取清晰画面，建议准备下列 5 张：
   - 启动/主界面，显示“对牛弹珠”名称；
   - 发射前的棋盘画面；
   - 普通钉子变色计分画面；
   - 紫色重置钉或橙色爆炸钉触发画面；
   - 关卡达标、获得牛币或进入下一关画面。

## 源码整理规则

本项目当前自研脚本位于 `assets/scripts/`。导出前按登记系统格式排版：A4、黑白、单面、页码连续；源码每页通常不少于 50 行。若全部源程序不足 60 页，提交全部；达到或超过 60 页时，按系统要求提交前、后各连续 30 页。不要伪造、补造或混入第三方引擎源码。

## 提交前核对

- [ ] 著作权人名称与抖音小游戏开发者主体一致。
- [ ] 软件名称、简称、版本号在申请表、说明书、源码页眉中完全一致。
- [ ] 说明书中的玩法与实际可运行版本一致。
- [ ] 截图真实、清晰，展示游戏名称和核心玩法。
- [ ] 所有美术、音效、代码均有可使用的权利或授权证明。
