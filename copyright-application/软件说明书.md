## 2. 软件简介

《对牛弹珠》是一款纵屏 2D 物理弹珠闯关游戏。玩家操控顶部的小牛发射器，通过拖动屏幕确定弹珠的发射方向，松开后利用重力、边界和钉子的碰撞获得积分。游戏采用卡通牧场主题，将小牛、牛铃钉、草地和围栏作为主要视觉元素，适用于移动端碎片化休闲体验。

## 3. 主要功能

### 3.1 弹珠发射与物理碰撞

玩家在顶部发射区向下拖动并松开，系统根据瞄准方向为弹珠施加初速度。弹珠在棋盘内受重力作用，与两侧和顶部墙体、普通钉子及特殊钉子发生物理碰撞；当弹珠从底部离开棋盘后，本回合结束。

### 3.2 普通钉子计分

普通牛铃钉共有绿色、蓝色、灰色三种状态。首次命中绿色钉子获得 3 分并变为蓝色；再次命中获得 2 分并变为灰色；第三次命中获得 1 分后消失。钉子状态在同一关卡的不同弹珠之间保留。

### 3.3 特殊钉子

紫色重置钉在被命中后恢复全部普通钉子的初始状态，并移动到新的位置。橙色爆炸钉在被命中后触发一定范围内普通钉子的计分效果，每关仅可触发一次。不同状态钉子及特殊钉子会播放不同的碰撞音效。

### 3.4 特殊弹珠与关卡推进

系统按发射次数轮换弹珠类型：普通球为默认类型；每第 3 球为高弹力球，具有更强反弹能力；每第 5 球为分裂球，在首次命中普通钉子后分裂为两颗弹珠。玩家累计积分达到当前关卡目标后，在本回合所有弹珠离场后进入下一关，并获得牛币奖励。

### 3.5 本地数据与统计

游戏在本地保存最高关卡和牛币数量，并记录开局、发射、钉子命中、特殊钉触发、回合结束和关卡完成等事件，为后续平台统计与运营调优提供基础。激励视频广告通过独立适配模块预留，未配置广告位时不会影响游戏核心流程。

## 4. 操作方法

1. 进入游戏棋盘后，将手指放在顶部小牛发射器附近。
2. 向下拖动手指，观察瞄准辅助线。
3. 松开手指，发射弹珠。
4. 观察钉子碰撞、分数变化和特殊效果。
5. 待所有弹珠从底部离开棋盘后，继续发射下一颗弹珠或进入下一关。

## 5. 界面说明

游戏顶部显示当前关卡、实时积分、牛币数量和最高关卡；中部为弹珠碰撞棋盘；顶部中央为小牛发射器；底部显示当前操作提示和特殊弹珠说明。棋盘采用蓝天、草地、围栏和花朵组成的卡通牧场背景，普通钉子和特殊钉子通过颜色进行状态区分。

## 6. 主要特点

- 单指拖动即可完成瞄准和发射，操作门槛低。
- 基于物理碰撞的随机路径与钉子消耗机制，增强重复游玩的变化。
- 普通钉子、重置钉、爆炸钉和特殊弹珠共同形成轻量策略选择。
- 纵屏布局适配移动端，画面中心保持清晰的玩法可读性。
- 采用本地优先的统计和奖励数据结构，便于后续接入小游戏平台服务。
